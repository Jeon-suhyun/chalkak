# 찰칵사전 📄 — 찍으면 풀리는 서류 용어

> 2026 안양대학교 AI 경진대회 본선 출품작 · 팀 For God (AI26-024) · 전수현, 김은민 (AI융합학과)

계약서·보험 약관·진단서를 처음 보는 20대가 어려운 용어를 모른 채 서명하는 문제를 해결합니다.
**사진이나 PDF를 올리면 → 어려운 용어에 빨간 상자가 표시되고 → 누르면 출처가 붙은 쉬운 설명이 나옵니다.**
표시되지 않은 궁금증은 서류 내용을 근거로 질문할 수 있습니다.

## 핵심 기능
| 기능 | 설명 |
|---|---|
| 글자 읽기 | 텍스트 PDF는 PyMuPDF로 바로 추출, 스캔 PDF·사진은 EasyOCR(한국어)로 인식. 휴대폰 사진 회전 보정, 인식 실패 시 재촬영 안내 |
| 용어 표시 | 용어 DB(약 1,270개)와 매칭해 위치에 빨간 상자 표시. OCR 띄어쓰기 오류 허용, 두 글자 용어는 단어 첫머리에서만 인정(오탐 방지) |
| 쉬운 설명 | 팀이 쓴 설명은 그대로, 공공 사전의 공식 정의는 **그 정의만 근거로** AI가 쉽게 풀어 쓰고 원문·출처를 함께 표시 |
| AI 추가 추출 | 사전에 없는 어려운 용어를 AI가 서류 맥락에서 골라 설명 (출처: "AI 생성"으로 구분 표시) |
| 질문 챗봇 | 질문과 관련된 용어를 사전에서 검색(RAG)해 서류 내용과 함께 AI에 전달. 서류 속 기간은 코드가 직접 계산해 사실로 제공(예: 6개월 계약 → 1년 미만). 조항은 원문 그대로 인용 |

## 실행 방법
```bash
pip install -r requirements.txt
streamlit run app.py
```
- OpenAI 키(선택): `.streamlit/secrets.toml`에 `OPENAI_API_KEY = "sk-..."` (저장소에는 포함하지 않음)
- 키가 없어도 사전 매칭 → 빨간 표시 → 설명 보기는 동작합니다.
- 테스트용 가상 서류: `테스트자료/` (근로계약서 PDF·사진, 보험약관 PDF)

## 용어 DB
| 파일 | 출처 | 개수 | 이용 조건 |
|---|---|---|---|
| `data/onbid.csv` | 한국자산관리공사 온비드 용어사전 (공공데이터포털) | 789 | 공공데이터 |
| `data/hira.csv` | 건강보험심사평가원 건강보험 용어사전 (공공데이터포털) | 349 | 공공누리 제1유형(출처표시) |
| `terms.csv` | 팀 정리: 고용노동부 표준근로계약서·국토교통부 주택임대차표준계약서 항목, 보험 표준약관 용어. 항목별 근거 법조항(`basis`) 표기 | 131 | 팀 작성 |

- 원본 CSV는 `raw_data/`, 변환은 `python build_terms.py`
- 예선 계획에서 바꾼 점: 한국보건의료인국가시험원 용어사전은 확인 결과 국가시험 운영 용어(감독관·문항 등)여서 제외했고, 공공 보험 약관 용어사전이 없어 보험 용어는 팀이 직접 정리했습니다.

## 개인정보와 한계
- 이름·주민번호·주소·전화번호는 사용자가 가린 뒤 올리도록 안내하고, 올린 파일은 서버에 저장하지 않습니다.
- 법률·의료 자문이 아니며, 사기 여부를 판정하지 않습니다. 모든 설명에 출처와 안내 문구를 표시합니다.
- AI 설명은 틀릴 수 있어 출처(공공 사전·팀 정리·AI 생성)를 구분해 보여 줍니다.

## 생성형 AI 활용
1. **서비스 기능**: OpenAI API(gpt-4o-mini)로 사전 밖 용어 추출, 공식 정의의 쉬운 풀이, 질문 답변
2. **기획**: Claude로 발표자료 문구 초안, 공공 용어사전 조사
